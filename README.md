# Yize Wang — Personal Website

[Visit the website](https://yizewang.github.io/)

## Repository Structure

| Path | Purpose |
| --- | --- |
| `data/` | Website content, career entries, and media metadata |
| `templates/` | Source template for the sharing preview image |
| `css/`, `js/` | Website styles and interactions |
| `images/` | Original media, optimized previews, and site icons |
| `scripts/` | Page generation, validation, and public-file packaging |
| Root HTML files | Generated homepage and redirects for previous page links |
| `.github/workflows/` | GitHub Pages publishing workflow |

Only the HTML pages, site assets, and revision marker are published. Local
previews and temporary work belong in the ignored `artifacts/` directory.
